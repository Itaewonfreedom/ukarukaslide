# Ukaruka Slide

Android 9 이상 휴대폰·태블릿용 로컬 사진 화면 보호기.

## 사진과 재생
- 여러 기기 앨범을 선택하며, 재생을 시작할 때 사진 목록을 다시 읽습니다.
- 랜덤 / 오래된 순 / 최신 순. 시간순 모드는 같은 날, 촬영 간격 2시간 이내의 사진을 묶어 내부 순서를 섞습니다.
- 연사 후보 줄이기: 같은 앨범에서 2초 안에 찍힌 사진 중 한 장을 고릅니다. 이미지 중복 판정은 아니며 설정에서 끌 수 있습니다.
- 가로 화면에서는 같은 추억 묶음의 세로 사진 두 장을 짝지어 보여줍니다. 짝이 없으면 한 장으로 표시합니다.
- 한 장 보기와 두 장 보기 모두 사진 비율을 유지하며 각 영역을 여백 없이 채웁니다. 두 사진 사이에도 간격을 두지 않습니다.
- 기기 내 Android FaceDetector로 얼굴 영역을 추정해 크롭 위치를 조절합니다. 정면 얼굴 중심의 검출이라 옆얼굴·작은 얼굴 등을 놓칠 수 있습니다. 얼굴 검출 여부와 관계없이 화면 채우기를 우선하므로 가장자리나 일부 얼굴이 잘릴 수 있습니다.
- 사진이 사라질 때까지 한 방향의 느린 줌·이동과 크로스페이드. 왕복하지 않습니다.

## 조작
- 터치: 날짜와 조작 메뉴 (촬영일이 없으면 저장일로 표시).
- 좌우 스와이프: 이전·다음. 최근 100개 슬라이드 기록을 유지합니다.
- 길게 누르기 또는 메뉴 버튼: 일시정지·재생.
- 메뉴의 사진별 숨기기: 원본 삭제 없이 앱에서 제외. 두 장 화면에서는 왼쪽/오른쪽을 각각 선택합니다.
- 사진 · 시계 · 야간 설정에서 숨긴 사진 전체 복원.

## 시계와 야간
시계·날짜 크기, 글꼴, 기준 위치, 초 표시를 설정합니다. 번인 완화를 위해 위치를 조금씩 옮깁니다.
야간은 기본 꺼짐이며 시작/종료 시각, 5–50% 밝기, 검은 화면을 설정할 수 있습니다.
자정을 넘는 시간도 지원하며 시작=종료는 비활성입니다. 검은 화면에서는 사진과 시계를 숨기고 재생을 멈춘 뒤 종료 시각에 이어갑니다.
현재 기기의 시간대와 시각을 사용하고 약 15초 이내에 반영합니다. 앱 창 밝기만 변경하며 종료하면 복원합니다.
검은 화면은 기기 전원을 끄는 기능이 아닙니다.

## 설치·설정
### 실험 브랜치: feature/fold-hologram
- 설정 → 힌지 홀로그램 전환 (기본 꺼짐). 좌우로 접는 폴더블용 각도 기반 원근 변형과 좌측 디졸브입니다.
- 설정 → 힌지 · 양쪽 화면 테스트: 센서 각도와 공개 WindowArea API의 지원 상태를 표시합니다. 지원 기기에서만 듀얼 화면 세션을 요청하며 시스템 확인창이 나타날 수 있습니다. 요청 실패 시 일반 화면으로 계속 재생합니다.
- 보조 화면은 같은 장면을 다시 그리므로 사진을 별도로 디코딩하거나 셔플하지 않습니다. 화면 밝기/전원 전환 시점은 OS가 결정하며 앱이 강제로 바꾸지 않습니다. 양쪽 화면 테스트는 Activity 미리보기 전용입니다.
- Activity의 일시 중단 및 구성 변경에서 사진·셔플 큐·히스토리·줌 방향·재생 시점을 보존합니다. DreamService는 같은 서비스 인스턴스의 재연결에서 복원합니다. 프로세스 종료나 서비스 재생성 후 복원은 지원하지 않습니다.
- 화면 크기 변화 중 이전 사진 구도를 기준으로 힌지 각도에 맞춰 새 구도로 연결합니다. 물리 좌표나 사용자 시점을 보정한 진짜 홀로그램은 아니며, 화면 판별의 600dp 보조 기준은 기기별 검증이 필요합니다.
- 검증할 항목: 천천히 열기/중간 정지/다시 닫기, 빠르게 여러 번 열고 닫기, 두 장 보기, 사진 전환 도중 접기, 일시정지 중 접기, 야간 검은 화면, 센서/듀얼 API 미지원 기기. 실제 Fold8과 삼성 화면 보호기 동작은 아직 검증하지 않았습니다.

사진 권한을 모두 허용하고 앨범을 선택한 다음 슬라이드를 재생하세요.
시스템 화면 보호기 설정에서 Ukaruka Slide를 선택할 수 있습니다.
Google Photos 로그인, 인터넷 권한, 알림 접근 기능은 없습니다.

## 개발·검증
JDK 17, Android SDK 35, Gradle wrapper를 사용합니다.

    ./gradlew :app:compileDebugKotlin :app:testDebugUnitTest

푸시와 PR에서는 컴파일·단위 테스트만 수행합니다. APK 빌드는 GitHub Actions의 수동 실행에서만 수행합니다.
실제 Galaxy 기기에서 얼굴 구도, 세로/가로 전환, 제스처, 화면 보호기의 야간 밝기는 별도 확인이 필요합니다.

## 개인정보
사진·얼굴 영역 분석은 기기 안에서 처리합니다. 숨기기는 앱의 제외 목록만 변경합니다.
서명키와 개인 사진은 저장소에 포함하지 않습니다.
